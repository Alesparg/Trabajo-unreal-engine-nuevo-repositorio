 7. PRIVACY & TELEMETRY
----------------------------------------------------------------

The Plugin collects two categories of data, both auditable
in Settings > Privacy:

  (a) Anonymous usage telemetry (ON by default): tool names
      that ran, success / failure, plugin + engine version,
      crash stack traces. Does NOT include prompts, AI
      responses, asset names, or anything project-identifying.
      Turn off: Settings > Privacy > Anonymous telemetry > Off.

  (a-detailed) Detailed diagnostics (OFF by default, new in
      v0.15.5): richer plumbing-level events to catch silent
      bugs (router decisions, compile results, memory-fetch
      timeouts, AI hallucinated node names, audit findings,
      token/cost ledger). Includes Blueprint names and
      /Game/... asset paths from your project. Does NOT
      include prompt text, AI response text, account email,
      API keys, or OS user-folder paths (those are stripped
      client-side before send). On first launch after
      updating to v0.15.5, a consent dialog asks whether to
      enable. Togglable any time at Settings > Privacy >
      Detailed diagnostics. Full disclosure at
      https://ai.locodev.dev/privacy/telemetry.

  (b) Prompt sharing (OFF by default): prompt text plus the
      AI's response. Collected ONLY if you explicitly opt in
      via Settings > Privacy > Share prompt examples. Helps
      us reproduce bugs faster. Togglable any time; previously
      shared prompts can be wiped via the Delete-shared-prompts
      button in the same panel.

  (c) Bug reports (per-report consent): Settings > Help >
      Report a bug opens a form where you can submit a
      description plus optional bundles (recent log tail,
      last 10 chat turns, viewport screenshot, contact email).
      Each report is its own conscious decision — preview
      pane shows the exact redacted payload before send.
      No "always send bug reports" toggle. Stored in
      loco_bug_reports, INSERT-only anon RLS.

The Plugin also runs two opt-in remote surfaces that default
OFF:

  - Live Dashboard presence (Settings > Live Dashboard):
    publishes project name, engine version, plugin version,
    and last-seen timestamp to your own dashboard at
    ai.locodev.dev/dashboard/live. No prompts or content.

  - Live Dashboard remote commands: lets the dashboard send a
    small whitelist of safe commands (health_check,
    take_screenshot, read_logs, get_project_status, create_task).
    Queue-only by default. Auto-submit is a separate Local-Dev
    toggle; remote tasks run under the Remote-task permission
    floor you choose in Settings.

  - Claude Code Bridge (Settings > Bridge): exposes the
    plugin's MCP endpoint on 127.0.0.1 with a per-launch token
    so an external Claude Code workspace session can call the
    same Blueprint tools. Token-gated; 127.0.0.1-only; never
    reachable from the LAN.

Full privacy policy: https://ai.locodev.dev/privacy
